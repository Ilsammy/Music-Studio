Music Studio is a simple and intuitive music production application designed to help you create, edit, and manage your music projects with ease. Despite its lightweight and beginner-friendly interface, it includes many of the features you would expect from professional and paid music software.

✨ Features
Easy-to-use interface
Music creation and editing tools
Project management
Lightweight and fast
Beginner friendly
🚀 Getting Started
Download the latest release.
Open Folder and press to .bat file "start-musicstudio"
Start creating your music!
🐞 Bugs & Feedback
As this is the very first release, you may encounter bugs or unexpected behavior.
